## TLDR

SimDrive is not offered as a commercial product (INIT-2026-605). There are
no paid tiers, no trial, and nothing to activate — every tool is available
immediately after `pip install simdrive`, under the
[Elastic License 2.0](https://www.elastic.co/licensing/elastic-license).

## Why there's nothing to license

Earlier versions shipped a machine-locked, Ed25519-signed trial/paid
licensing system gating the MCP tool surface. That commercial model was
retired 2026-08-26. If you're running one of those older versions and see a
license-related error, update to the latest release.

See also: [License](/license/paid) for the current, simplified page.
